# Flowledger

A minimalist personal finance tracker designed to monitor daily income, expenses, and real-time cash flow with a calm, glassmorphic UI.

## Features

- **Real-Time Cash Flow**: Live balance, monthly income, expense metrics, and visual cash flow indicators.
- **Weekly & Monthly Budgets**: Visual budget progress bars, over-budget alerts, and instant budget deletion with undo.
- **Auto-Detect Bank SMS**: Automatic detection and parsing of incoming bank SMS transactions via native Android telephony channels (no third-party cloud dependencies).
- **Transaction History & Filters**: Search, category filtering (All, Expenses, Income), and multi-level groupings (Date, Month, Year).
- **Glassmorphic Ambient Design**: High-performance fluid gradients, frosted glass cards, and configurable ambient backgrounds.
- **Biometric & PIN Security**: App lock protection with biometrics and secure fallback PIN.
- **Cloud Firestore Sync**: Real-time multi-device cloud synchronization.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/NKB2005/Flowledger.git
   ```
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run tests:
   ```bash
   flutter test
   ```
4. Run the application:
   ```bash
   flutter run
   ```
